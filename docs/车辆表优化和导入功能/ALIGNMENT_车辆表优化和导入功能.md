# 车辆表优化和XLSX导入功能 - 对齐文档

## 1. 项目背景

### 1.1 当前状态
- 现有车辆表（vehicles）包含基本的车辆信息字段
- 车牌号（license_plate）和车厢号（carriage_number）字段均为可选
- 缺少车辆类型区分机制（单车/挂车）
- 缺少常用公司记录功能
- 无批量导入功能

### 1.2 技术栈
- 后端：Flask + SQLAlchemy
- 前端：Vue 3 + Element Plus
- 数据库：SQLite

## 2. 需求分析

### 2.1 核心需求

#### 2.1.1 必填字段约束优化
**需求描述**：车辆表必须包含以下两个必填字段之一：
- 车牌号或车厢号必须有一个（不能都为空）
- 容积字段必须填写

**格式要求**：
- 车厢号格式：在车牌号基础上增加"挂"字，例如：皖A36T3挂
- 容积：数值类型，支持小数

#### 2.1.2 新增字段需求
**车辆类型字段**：
- 字段名：vehicle_category
- 类型：字符串
- 取值："单车" 或 "挂车"
- 判断逻辑：使用车厢号的是挂车，其他是单车

**常用公司字段**：
- 字段名：frequent_companies
- 类型：文本（JSON格式存储）
- 功能：记录使用过该车辆的所有公司（支持多公司记录）

#### 2.1.3 XLSX导入功能
**功能描述**：
- 支持Excel文件批量导入车辆信息
- 导入模板包含所有字段
- 数据验证和错误提示
- 导入结果反馈

**支持字段**：
- 车牌号（license_plate）
- 车厢号（carriage_number）
- 容积（actual_volume）
- 车辆类型（vehicle_type）
- 车辆分类（vehicle_category）- 新增
- 常用公司（frequent_companies）- 新增
- 备注（notes）

## 6. 风险评估

### 6.1 技术风险
- **数据库迁移风险**：新增字段和约束可能影响现有数据
- **文件上传安全风险**：需要验证文件类型和大小
- **性能风险**：大批量导入可能影响系统性能

### 6.2 业务风险
- **数据一致性风险**：导入数据可能与现有数据冲突
- **用户体验风险**：新的必填验证可能影响用户操作习惯
