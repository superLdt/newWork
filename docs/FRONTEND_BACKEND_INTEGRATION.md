# 前后端对接完成说明

## 概述

本文档说明用户管理和角色管理模块的前后端对接完成情况，包括API接口对接、功能实现和使用说明。

## 已完成的对接工作

### 1. 后端API接口

#### 用户管理API (`/api/v1/users`)
- ✅ `GET /users` - 获取用户列表（支持分页）
- ✅ `GET /users/{id}` - 获取用户详情
- ✅ `POST /users` - 创建用户（支持角色分配）
- ✅ `PUT /users/{id}` - 更新用户信息（支持角色更新）
- ✅ `DELETE /users/{id}` - 删除用户（软删除）

#### 角色管理API (`/api/v1/roles`)
- ✅ `GET /roles` - 获取角色列表（包含用户数统计）
- ✅ `GET /roles/{id}` - 获取角色详情
- ✅ `POST /roles` - 创建角色
- ✅ `PUT /roles/{id}` - 更新角色信息
- ✅ `DELETE /roles/{id}` - 删除角色

#### 用户角色关联API
- ✅ `GET /users/{user_id}/roles` - 获取用户的所有角色
- ✅ `POST /users/{user_id}/roles/{role_id}` - 为用户分配角色
- ✅ `DELETE /users/{user_id}/roles/{role_id}` - 移除用户的角色

## 使用说明

### 1. 启动服务

#### 后端服务
```bash
cd backend
python run.py
```
服务地址：http://localhost:5000

#### 前端服务
```bash
cd frontend
npm run dev
```
服务地址：http://localhost:3000

### 2. 功能使用

#### 用户管理
1. 访问 `/settings/users` 页面
2. 点击"添加用户"创建新用户，可同时选择角色
3. 使用搜索和筛选功能查找用户
4. 点击"编辑"修改用户信息
5. 使用状态开关启用/禁用用户
6. 点击"分配角色"管理用户角色

#### 角色管理
1. 访问 `/settings/roles` 页面
2. 点击"添加角色"创建新角色
3. 点击"编辑"修改角色描述
4. 查看每个角色的用户数统计
5. 删除角色（需确保无关联用户）

### 3. 数据流程

#### 用户创建流程
1. 前端表单验证
2. 发送POST请求到 `/api/v1/users`
3. 后端创建用户并分配角色
4. 返回完整用户信息
5. 前端更新列表显示

#### 角色分配流程
1. 获取用户当前角色
2. 显示可分配角色列表
3. 调用角色分配/移除API
4. 实时更新角色显示
