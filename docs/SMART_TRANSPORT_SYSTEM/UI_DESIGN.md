# 人工派车流程系统 - 界面设计

## 1. 界面设计概述

人工派车流程系统的界面设计基于角色权限进行划分，主要包括以下几个角色的界面：

1. **调度负责人界面**：负责审批运输需求、提出运输需求
2. **车间地调界面**：提出运输需求、确认车型信息、执行车辆合并操作、执行降档操作、确认运输任务完成情况
3. **供应商（委办公司）界面**：派遣委办车辆执行运输任务，最终确认
4. **班组界面**：派遣自办车辆执行运输任务，最终确认
5. **承运商界面**：使用自办车辆，最终确认，管理外包驾驶员，负责车辆派遣

## 2. 通用界面组件

### 2.1 导航栏

导航栏位于页面顶部，包含以下元素：

- 系统Logo
- 主导航菜单（根据用户角色显示不同的菜单项）
- 用户信息（用户名、角色）
- 通知图标（显示未读通知数量）
- 退出登录按钮

### 2.2 任务列表组件

任务列表组件用于显示派车任务列表，包含以下元素：

- 搜索框（支持按任务ID、状态、日期等搜索）
- 筛选选项（按状态、日期范围、派车轨道等筛选）
- 任务列表表格（显示任务ID、需求日期、起始站点、路线名称、运输类型、状态等信息）
- 分页控件
- 操作按钮（查看详情、编辑、删除等，根据任务状态和用户角色显示不同的操作按钮）

### 2.3 任务详情组件

任务详情组件用于显示派车任务的详细信息，包含以下元素：

- 任务基本信息（任务ID、需求日期、起始站点、路线名称、运输类型等）
- 任务状态信息（当前状态、派车轨道、当前处理人角色等）
- 车辆信息列表（车牌号、司机姓名、联系电话、车型、载重量等）
- 状态历史记录（状态变更历史、操作人、操作时间、备注等）
- 操作按钮（根据任务状态和用户角色显示不同的操作按钮）

## 3. 角色界面设计

### 3.1 调度负责人界面

#### 3.1.1 首页仪表盘

调度负责人首页仪表盘显示系统整体运行情况，包含以下元素：

- 任务状态统计（各状态任务数量的饼图）
- 待处理任务列表（需要审核的任务）
- 今日新增任务数量
- 今日完成任务数量
- 异常任务提醒

#### 3.1.2 任务审核界面

任务审核界面用于审核派车任务，包含以下元素：

- 任务基本信息（只读）
- 审核意见输入框
- 审核通过按钮
- 审核拒绝按钮

#### 3.1.3 创建任务界面

创建任务界面用于创建新的派车任务，包含以下元素：

- 任务基本信息表单（需求日期、起始站点、路线名称、运输类型等）
- 派车轨道选择（轨道A或轨道B）
- 供应商选择（委办公司、班组、承运商）
- 提交按钮

### 3.2 车间地调界面

#### 3.2.1 首页仪表盘

车间地调首页仪表盘显示与车间相关的任务情况，包含以下元素：

- 我创建的任务列表
- 待确认的任务列表
- 今日完成任务数量
- 异常任务提醒

#### 3.2.2 创建任务界面

创建任务界面用于创建新的派车任务，包含以下元素：

- 任务基本信息表单（需求日期、起始站点、路线名称、运输类型等）
- 提交按钮

#### 3.2.3 车辆合并界面

车辆合并界面用于执行车辆合并操作，包含以下元素：

- 任务基本信息（只读）
- 车辆列表（可选择多辆车进行合并）
- 目标车辆选择
- 合并原因输入框
- 合并按钮

#### 3.2.4 降档操作界面

降档操作界面用于执行降档操作，包含以下元素：

- 任务基本信息（只读）
- 车辆信息（只读）
- 降档后容量输入框
- 降档原因输入框
- 降档按钮

#### 3.2.5 车辆容积更新界面

车辆容积更新界面用于车间地调修改车辆实际容积，包含以下元素：

- 车辆基本信息（只读，包括车牌号、车厢号、原始载重量、当前实际容积）
- 车型折算系数表（参考信息）
- 新实际容积输入框
- 修改原因输入框
- 容积照片上传区域
- 审批凭证上传区域
- 提交按钮

#### 3.2.6 任务确认界面

任务确认界面用于确认任务完成情况，包含以下元素：

- 任务基本信息（只读）
- 车辆信息（只读）
- 确认备注输入框
- 确认完成按钮

### 3.3 供应商（委办公司）界面

#### 3.3.1 首页仪表盘

供应商首页仪表盘显示与供应商相关的任务情况，包含以下元素：

- 待响应任务列表
- 已响应任务列表
- 今日完成任务数量

#### 3.3.2 响应任务界面

响应任务界面用于供应商响应派车任务，包含以下元素：

- 任务基本信息（只读）
- 车辆信息表单（可添加多辆车）
  - 车牌号输入框
  - 司机姓名输入框
  - 司机电话输入框
  - 车型选择
  - 载重量输入框
  - 实际容积输入框
  - 货票号输入框
- 响应备注输入框
- 提交响应按钮

### 3.4 班组界面

班组界面与供应商界面类似，主要区别在于班组派遣的是自办车辆。

#### 3.4.1 首页仪表盘

班组首页仪表盘显示与班组相关的任务情况，包含以下元素：

- 待响应任务列表
- 已响应任务列表
- 今日完成任务数量

#### 3.4.2 响应任务界面

响应任务界面用于班组响应派车任务，包含以下元素：

- 任务基本信息（只读）
- 车辆信息表单（可添加多辆车）
  - 车牌号输入框
  - 司机姓名输入框
  - 司机电话输入框
  - 车型选择
  - 载重量输入框
  - 实际容积输入框
  - 货票号输入框
- 响应备注输入框
- 提交响应按钮

### 3.5 承运商界面

承运商界面与供应商界面类似，但增加了外包驾驶员管理功能。

#### 3.5.1 首页仪表盘

承运商首页仪表盘显示与承运商相关的任务情况，包含以下元素：

- 待响应任务列表
- 已响应任务列表
- 今日完成任务数量
- 驾驶员状态统计

#### 3.5.2 响应任务界面

响应任务界面用于承运商响应派车任务，包含以下元素：

- 任务基本信息（只读）
- 车辆信息表单（可添加多辆车）
  - 车牌号输入框
  - 司机姓名输入框（可从驾驶员列表中选择）
  - 司机电话输入框
  - 车型选择
  - 载重量输入框
  - 实际容积输入框
  - 货票号输入框
- 响应备注输入框
- 提交响应按钮

#### 3.5.3 驾驶员管理界面

驾驶员管理界面用于管理外包驾驶员，包含以下元素：

- 驾驶员列表表格（显示姓名、电话、状态等信息）
- 添加驾驶员按钮
- 编辑驾驶员按钮
- 删除驾驶员按钮

### 6.2 车辆容积计算规则

1. 车辆实际容积应根据实际测量结果确定
2. 当无法直接测量时，可参考车型折算系数表进行估算
3. 车间地调在修改车辆容积时，必须上传容积照片和审批凭证
4. 容积修改不得超过原始容积的±20%范围

## 7. 响应式设计

系统界面采用响应式设计，适配不同尺寸的屏幕：

1. **桌面端**：完整显示所有功能和信息
2. **平板端**：调整布局，确保关键功能可用
3. **移动端**：简化界面，保留核心功能

## 7. 界面交互设计

### 7.1 表单验证

- 实时表单验证，输入错误时显示错误提示
- 提交前进行完整性检查，防止提交不完整的表单

### 7.2 状态反馈

- 操作成功时显示成功提示
- 操作失败时显示错误提示，并给出解决建议
- 长时间操作时显示加载动画

### 7.3 权限控制

- 根据用户角色显示不同的菜单项和操作按钮
- 未授权的操作按钮显示为禁用状态

## 8. 总结

本文档设计了人工派车流程系统的界面，包括通用界面组件、各角色界面设计、界面流程图和界面原型示例。这些界面设计旨在提供良好的用户体验，支持多角色协作完成派车任务。

在实际实现过程中，需要根据具体业务需求进行调整和优化，确保界面设计能够满足业务需求，并保持良好的用户体验。同时，需要注意界面的一致性和可用性，确保用户能够轻松上手使用系统。
