# 任务详情页面优化需求对齐文档

## 项目背景
当前派车任务详情页面需要功能增强和样式优化，以支持不同角色的差异化操作和更好的用户体验。

## 需求分析

### 1. 新增显示字段
- **需求时间**：显示具体的时间要求（小时:分钟）
- **发起时间**：显示任务创建时间
- 位置：在页面显著位置，与现有需求日期并列展示

### 2. 角色差异化按钮显示
基于RBAC权限系统，不同角色显示不同操作按钮：

| 角色 | 显示按钮 | 按钮样式 | 业务含义 |
|---|---|---|---|
| 区域调度员 | 审批、拒绝 | primary、danger | 任务初审 |
| 供应商 | 响应 | success | 接单响应 |
| 班组长 | 确认 | warning | 任务确认 |
| 外包管理公司 | 最终确认 | success | 最终审核 |
| 车间地调 | 发车确认 | primary | 执行确认 |

### 3. 新增功能组件
- **当前操作状态提示栏**：页面顶部固定显示，包含：
  - 当前任务状态
  - 下一步操作提示
  - 预计完成时间
- **操作按钮布局优化**：
  - 按钮按业务流程顺序排列
  - 使用图标增强识别性
  - 禁用状态清晰标识

### 4. UI样式优化
- **主色调**：蓝色渐变（#1e3c72 → #2a5298）
- **视觉层次**：
  - 卡片式布局
  - 阴影效果
  - 合理的留白和间距
- **响应式设计**：移动端适配

## 技术约束
- 使用Vue 3 + Element Plus
- 保持与现有权限系统集成
- 支持深色模式切换
- 确保向后兼容

## 验收标准
- [ ] 所有角色按钮正确显示
- [ ] 状态提示栏信息准确
- [ ] 样式符合设计规范
- [ ] 移动端响应式正常
- [ ] 无控制台错误

## 依赖分析
- 需要获取用户角色信息
- 需要任务状态流转API
- 需要权限验证服务

## 风险评估
- 权限判断逻辑复杂，需充分测试
- 状态流转需考虑并发情况
- 样式兼容性测试
