# ALIGNMENT_调度仪表盘

## 项目上下文分析
**技术栈**: Python Flask + Vue.js + SQLite
**架构模式**: 四层架构（表现层、应用层、服务层、数据层）
**业务域**: 运输调度管理系统

## 需求理解确认
### 核心功能需求
1. **任务统计概述**
   - 总任务数
   - 今日新增任务数
   - 即将超时任务数（基于created_at字段判断）

2. **状态分布栏**
   - 审批状态分布（audit_status字段统计）
   - 轨道类型分布（dispatch_track字段统计）

3. **紧急提醒区域**
   - 紧急任务列表（基于状态和创建时间筛选）

### 开发流程要求
1. 前端界面开发
2. 数据库配置检查
3. 调度管理菜单下新增仪表盘子菜单
4. 路由连接

## 技术约束和依赖
- 后端：Flask API扩展，需要新增仪表盘相关端点
- 前端：Vue组件开发，需要集成到现有路由系统
- 数据库：基于现有ManualDispatchTask模型进行统计查询
- 权限：需要确保只有调度管理权限的用户可以访问

## 验收标准
- [ ] 前端仪表盘界面美观易用
- [ ] 统计数据显示准确
- [ ] 状态分布图表清晰展示
- [ ] 紧急任务提醒功能正常
- [ ] 菜单导航正确配置
- [ ] API接口性能良好

## 识别风险
- 数据库查询性能需要考虑索引优化
- 时间计算需要考虑时区问题
- 权限控制需要与现有系统集成
